#Overview

This script reads raw data from a sample CSV file containing MAX6682 digital temperature sensor readings (Dout in decimal) and Unix timestamps in microseconds, transforms the values into degrees Celsius, and plots the results over time.

#Features and Requirements

- Converts Unix timestamps (in microseconds) to human-readable date-time formats with microsecond resolution
- Handles CSV files with any number of data points dynamically
- Generates a graph showing Temperature (°C) on the Y-axis against Time on the X-axis
